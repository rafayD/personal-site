# Rafay Din - Personal Website

A modern, responsive personal website showcasing my experience as a software engineer. Built with Next.js, TypeScript, and Tailwind CSS.

## 🚀 Live Site

**[https://rafaydin.fyi](https://rafaydin.fyi)**

## ✨ Features

- **Professional Hero Section** - Introduction with call-to-action buttons
- **Experience Showcase** - Detailed work history and achievements
- **Skills Display** - Technical skills and competencies
- **Project Portfolio** - Showcase of key projects and contributions
- **Contact Form** - Easy way for visitors to get in touch
- **Responsive Design** - Optimized for all devices
- **Dark/Light Theme** - Modern theme switching capability

## 🛠️ Tech Stack

- **Frontend**: Next.js 14, React, TypeScript
- **Styling**: Tailwind CSS, CSS Modules
- **UI Components**: Custom component library with shadcn/ui
- **Deployment**: Vercel
- **Icons**: Lucide React

## 🎯 Purpose

This website serves as my professional landing page, allowing potential employers, clients, and collaborators to:
- Learn about my background and experience
- View my technical skills and expertise
- See examples of my work and projects
- Easily get in touch for opportunities

## 📱 Sections

1. **Hero** - Introduction and quick actions
2. **Experience** - Professional background and achievements
3. **Skills** - Technical competencies and tools
4. **Projects** - Portfolio of notable work
5. **Contact** - Get in touch form and information

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/rafayD/personal-site.git

# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build
```
